PhotoSweep

在设备上发现重复照片、模糊照片、截图与值得保留的精彩画面，让相册整理更轻松。

使用帮助

  1. 首次打开时允许 PhotoSweep 完全访问照片。
  2. 在“清理”页扫描相册，查看重复照片、模糊照片和截图。
  3. 在“智能”页分析照片质量和可能包含敏感信息的图片。
  4. 删除前请逐项确认；系统会将删除的照片放入“最近删除”。

常见问题

为什么需要完全访问照片？
完整扫描、相似照片分组和删除操作需要照片图库权限。所有分析均在设备上完成。

照片会上传吗？
不会。PhotoSweep 不会上传照片、识别到的文字或扫描结果。

如何恢复购买？
前往 App 内“设置”，点按“恢复购买”。购买由 Apple ID 与 App Store 管理。

联系支持

如遇到问题，请在 GitHub Issues 中说明设备型号、iOS 版本和复现步骤。
